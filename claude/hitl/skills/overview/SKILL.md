# /hitl:overview — project foundation docs

Follow `${CLAUDE_PLUGIN_ROOT}/shared/conventions.md`.

Arguments: `$ARGUMENTS` — a project description, `refresh` (= option 1 below, no gate), or empty.

Docs dir: `.hitl/docs/`. Templates: `${CLAUDE_PLUGIN_ROOT}/shared/templates/{BUSINESS-CONTEXT,ARCHITECTURE,PATTERNS-CONVENTIONS}.md`.
Every generated section sits inside `<!-- AUTO-GENERATED:BEGIN <name> -->…<!-- AUTO-GENERATED:END <name> -->`.
Text outside those blocks is MANUAL and must stay byte-identical.

## 1. Prepare (no questions)
1. `hitl-index status --brief --soft`. If "not initialized" → `hitl-index init --json` with defaults and print
   `💡 Initialized with detected defaults. Run /hitl:setup later to confirm test commands.`
2. 🔍 `hitl-index index --all --json`, then `hitl-index map-md`.
   This writes the CODEBASE-MAP AUTO block and `index/index.md`. You never write CODEBASE-MAP yourself.
3. Check which of the three docs exist, and whether each still holds template placeholders (`[Problem this codebase solves` etc.).

## 2. ⛔ GATE (only when ≥1 doc exists with real content AND no arguments)
```
📚 Docs found: BUSINESS-CONTEXT ✅  ARCHITECTURE ✅  PATTERNS-CONVENTIONS ❌  CODEBASE-MAP ✅ (regenerated)
1. 💡 Update (refresh AUTO blocks, keep MANUAL text)
2. Regenerate AUTO blocks from scratch (MANUAL text still kept)
3. Only create missing docs
Project description (optional, empty = auto-detect):
```
END THE TURN.
- No docs (or only templates) → skip the gate, mode = create. Description = arguments, or auto-detect.
- `refresh` → mode = update, no gate. Any other non-empty argument → it is the description; mode = update if docs exist, else create.

## 3. Map in parallel
Spawn **three** `hitl:codebase-mapper` agents **in one message** (parallel Agent calls). Prompt for each:

```
focus: business | architecture | conventions
mode: create | update | regenerate
description: <user description or "auto-detect">
language: <language for doc prose: the user's language for business; English otherwise unless the user asked>
template: ${CLAUDE_PLUGIN_ROOT}/shared/templates/<DOC>.md
target: <abs project root>/.hitl/docs/<DOC>.md
index summary: <abs project root>/.hitl/index/index.md   (read-only; for structure, no signatures in docs)
config: <abs project root>/.hitl/hitl.config.json         (conventions focus: compare test setup)
```
Focus → doc: business → BUSINESS-CONTEXT.md, architecture → ARCHITECTURE.md, conventions → PATTERNS-CONVENTIONS.md.
Mode 3 ("only missing") → spawn mappers only for missing docs.

Each returns JSON `{doc, sections:[{name, marker}], notes, testing?}`. Do not re-read the docs they wrote.

## 4. Report (no further gate)
```
📚 Overview updated
BUSINESS-CONTEXT.md     project-goal ✅  domain-logic ⚠️  user-flows ❌  glossary ✅
ARCHITECTURE.md         tech-stack-roles ⚠️  component-roles ✅  system-interactions ✅  boundaries ❌
PATTERNS-CONVENTIONS.md naming ✅  code ✅  architecture ✅  testing ⚠️
CODEBASE-MAP.md         regenerated by hitl-index map-md (<files> files, <symbols> symbols)
Legend: ✅ unchanged  ❌ new  🗑️ removed  ⚠️ changed
```
- Add the mappers' `notes` (max 3 lines each) — e.g. unknowns marked "unknown".
- Conventions mapper `testing` vs `hitl.config.json` `commands.test` mismatch (e.g. docs say jest, config uses node --test)
  → `⚠️ Test setup differs from config: <detail>. Run /hitl:setup --reconfigure`.
- 🎯 next: `/hitl:plan <what you want to build>`.

## Rules
- Never put signatures or line numbers in these three docs (CODEBASE-MAP owns signatures).
- A mapper failure → show ❌ for that doc with its message; keep the other docs. Do not retry more than once.
